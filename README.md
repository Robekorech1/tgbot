# Telegram бот для получения погоды

Телеграм бот написан на Python с использованием различный библиотек

## Описание
PogodaBro — это удобный инструмент для быстрого получения прогноза погоды прямо в Telegram. Бот использует данные OpenWeatherMap API для предоставления точной информации о текущих погодных условиях.

### Основные возможности:
-  Получение погоды по геолокации пользователя
-  Детальная информация: температура, влажность, ощущаемая температура
-  Эмодзи-визуализация погодных условий
-  Удобная клавиатура с кнопками
- Информация о проекте и авторе
